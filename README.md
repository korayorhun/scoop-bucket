# korayorhun's Scoop bucket

[Scoop](https://scoop.sh) bucket for **[Sesli Okuma](https://github.com/korayorhun/SesliOkuma)** — read selected text aloud in any Windows app with one hotkey (natural voices, word highlighting, screen OCR, free translation).

```
scoop bucket add korayorhun https://github.com/korayorhun/scoop-bucket
scoop install korayorhun/sesliokuma
```

The manifest is updated automatically with every Sesli Okuma release.
